# Image Generation

Every turn closes with an `<img>` block under its prose and its `<state>`: a
prompt for an image generation AI depicting the scene the prose just narrated.
Write one every turn, in the same reply as the prose. There is no separate tool
and no second chance — a narration without it is an incomplete turn.

```
<img>
A low stone cellar lit by one guttering lantern...
</img>
```
