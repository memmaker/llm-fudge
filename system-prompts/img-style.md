# Image Generation

Every narration closes with an `<img>` block under its prose: a prompt for an
image generation AI depicting the scene the prose just narrated. Write one every
turn, in the same reply as the prose. There is no separate tool and no second
chance — a narration without it is an incomplete turn.

The block is cut out before the player sees the reply, so nothing in it is read
by them.

```
<img>
A low stone cellar lit by one guttering lantern...
</img>
```
