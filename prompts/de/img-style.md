# Bilderzeugung

Jede Erzählung endet unter ihrem Text mit einem `<img>`-Block: einem Prompt für
eine Bild-KI, der gerade erzählte Szene. Schreibe ihn in derselben Antwort wie
die Erzählung. Es gibt kein eigenes Tool und keine zweite Chance – eine
Erzählung ohne ihn ist unvollständig.

Der Block wird entfernt, bevor die spielende Person die Antwort sieht.

```
<img>
Ein niedriger Steinkeller, beleuchtet von einer flackernden Laterne …
</img>
```
